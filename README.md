# 🎬 JustStreamIt

## 📖 Description

JustStreamIt est une interface web permettant de consulter les meilleurs films à partir d'une API locale.

L'application met en avant le meilleur film du moment, affiche les films les mieux notés, propose des catégories fixes et dynamiques, ainsi qu'une fiche détaillée pour chaque film.

Ce projet a été réalisé dans le cadre de la formation Développeur d'application Python d'OpenClassrooms.

---

## ✨ Fonctionnalités

- Affichage du meilleur film
- Affichage des films les mieux notés
- Affichage des catégories Action et Drama
- Sélection dynamique d'une catégorie via un menu déroulant
- Ouverture d'une modale contenant les informations détaillées d'un film
- Bouton **Voir plus / Voir moins** pour chaque catégorie
- Placeholder lorsqu'une affiche est indisponible
- Interface responsive (mobile, tablette et desktop)

## 🚀 Installation

### 1. Cloner le projet

```bash
git clone <url-du-repository>
```

### 2. Lancer l'API OCMovies

Suivre les instructions du dépôt officiel de l'API :

https://github.com/OpenClassrooms-Student-Center/OCMovies-API-EN-FR

### 3. Démarrer le projet

Ouvrir simplement le fichier `index.html` dans votre navigateur.
